## Mistakes I made and how I fixed them
- First draft of tips in `docs.config.json` included invented claims (logs "do not wait", jump timing). Replaced with claims that come from the code or docs. Regenerated docs.
- Showcase "Play now" pointed at the site root, not `/play/`. Fixed in `docs/index.html` and `play_url`.
- A shell `rm` with an unexpanded variable was blocked by the safety check and did not run. Used literal paths for later steps.
- Hero config initially used the 900x1030 default size, which does not match the retro stills. Set `"size": "700x800"` for the hero.

## Learnings for a future agent
- docs-kit writes README.md, so hand-written README must come after the kit run, or the kit run must be the last step.
- `shots.mjs --hero --only none` runs only the hero, since `--only` with an unknown id skips all stills.
- Keep the stills folder curated before running docs-kit: it copies all PNGs, including ui_* and smoke files.
