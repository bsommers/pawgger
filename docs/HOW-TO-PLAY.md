# How to play Pawgger

**Goal:** Hop Colby across every lane, fill the five Micro Center bays, and get out of Pete's way.

## Controls

| Input | Action |
| --- | --- |
| Arrow keys / WASD | Hop (one cell per press) |
| Space / Z / X | Jump |
| Enter | Confirm |
| Escape | Back |
| P | Pause |
| G | Cycle style: retro, ghibli, toon |

## Tips

- Pete patrols the median on later levels, so watch his sweep before you cross.
- Press G to cycle between retro, ghibli and toon, or open the page with ?style=retro, ?style=ghibli or ?style=toon.
- Run the autopilot (botplay) to watch one way through levels 1-10.
